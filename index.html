Orkestrasi Web Lokal Tanpa Bloat, Langsung di User-Space.

xabi mengelola binary native nginx, php-fpm / php-cgi.exe, mariadbd, mkcert, dan cloudflared tanpa service sistem root atau wrapper berat. Ikuti panduan prosedural 7 langkah di bawah sesuai platform pilihanmu (Windows PowerShell).

Config Directory (XDG_CONFIG_HOME)
%USERPROFILE%\.config\xabi\ config.toml, sites.toml, nginx/, certs/, php/
Data Directory (XDG_DATA_HOME)
%USERPROFILE%\.local\share\xabi\ db/ (MariaDB datadir), bin/ (shims/symlinks), php/
Runtime Directory (XDG_RUNTIME_DIR)
%TEMP%\xabi\ .pid, log & nginx temp buffers
Hosts & PHP Default Upstream
127.0.0.1:9000 • ...\etc\hosts Blok terkelola # BEGIN xabi ... # END xabi

Instalasi Binary dari Source

              
Compile binary statis xabi dengan Go stdlib dan pasang ke direktori binary user agar dikenali di PATH.

            

            
          


          

            

              
1. Clone & Build di Windows

              
Gunakan go build dengan flag strip simbol agar binary ringkas dan siap pakai:

              

                

                  powershell • build & install
                  
                

                
git clone https://github.com/yusrb2/xabi.git
cd xabi
go build -trimpath -ldflags="-s -w -X main.version=v0.1.0" -o bin\xabi.exe .\cmd\xabi

$binDir = "$env:USERPROFILE\.local\share\xabi\bin"
New-Item -ItemType Directory -Force $binDir | Out-Null
Copy-Item .\bin\xabi.exe "$binDir\xabi.exe" -Force

              


              
2. Tambahkan ke User PATH

              
Menambahkan %USERPROFILE%\.local\share\xabi\bin ke PATH sekaligus mengaktifkan shim php.cmd & php-cgi.cmd yang dikelola xabi php:

              

                

                  powershell • user PATH + verifikasi
                  
                

                
$binDir = "$env:USERPROFILE\.local\share\xabi\bin"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$binDir*") {
    [Environment]::SetEnvironmentVariable("Path", "$userPath;$binDir", "User")
}

# Buka terminal baru lalu cek versi
xabi version

              

            


            

              
1. Clone, Build & Install di Linux

              
Gunakan Makefile bawaan untuk membangun binary statis (CGO_ENABLED=0) dan memasangnya ke ~/.local/bin/xabi (atau tambahkan PREFIX=/usr/local untuk system-wide):

              

                

                  bash • make install
                  
                

                
git clone https://github.com/yusrb2/xabi.git
cd xabi
make install
# Alternatif system-wide: sudo make PREFIX=/usr/local install

              


              
2. Pastikan PATH Mencakup Binary & PHP Shim

              
Tambahkan baris berikut ke ~/.bashrc atau ~/.zshrc agar xabi dan symlink PHP aktif terdeteksi terlebih dahulu:

              

                

                  bash / zsh • ~/.bashrc atau ~/.zshrc
                  
                

                
export PATH="$HOME/.local/bin:$HOME/.local/share/xabi/bin:$PATH"

# Reload shell lalu cek
xabi version

Diagnostik & Inisialisasi Stack

              
Siapkan direktori XDG, template config.toml & nginx.conf, datadir MariaDB, izin file hosts, dan akses port 80/443.

            

            
          


          

            

              xabi mencari binary nginx (wajib), serta php-fpm/php-cgi, mariadbd/mysqld, mkcert, dan cloudflared (opsional) di  dan PATH.
            


            

              
1. Pratinjau & Inisialisasi Environment (Windows)

              
Install dependency via Scoop/Winget/Laragon (pastikan nginx.exe, php-cgi.exe, mariadbd.exe, dan mkcert.exe ada di PATH), lalu jalankan xabi init:

              

                

                  powershell • init & doctor
                  
                

                
# Cek rencana tanpa mengubah sistem
xabi init --dry-run

# Buat XDG layout, config.toml, nginx.conf, datadir MariaDB, dan mkcert -install
xabi init

# Verifikasi kesiapan binary, port 80/443/3306, dan hosts
xabi doctor

              


              
2. Izin Write File hosts Sekali Saja

              
Agar xabi add dan xabi rm bisa mengedit C:\Windows\System32\drivers\etc\hosts tanpa selalu membuka terminal Administrator, beri izin Modify via PowerShell Administrator:

              

                

                  powershell (Administrator) • ACL hosts
                  
                

                
icacls "$env:SystemRoot\System32\drivers\etc\hosts" /grant "${env:USERNAME}:(M)"

              

              

                Catatan Port 80/443 di Windows: Windows tidak membutuhkan setcap. Jika xabi doctor melaporkan port 80/443 sibuk, pastikan IIS/Apache/Laragon berhenti atau ubah [ports] di %USERPROFILE%\.config\xabi\config.toml.
              

            


            

              
1. Izin /etc/hosts & Port 80/443 (setcap)

              
Beri write ACL sekali saja untuk user aktif pada /etc/hosts, lalu jalankan xabi init (yang otomatis mencoba menerapkan cap_net_bind_service=+ep pada binary nginx agar bisa bind port 80/443 tanpa root):

              

                

                  bash • hosts ACL, init & doctor
                  
                

                
# Izinkan user menulis /etc/hosts tanpa sudo saat xabi add/rm
sudo setfacl -m u:$USER:rw /etc/hosts

# Pratinjau rencana inisialisasi
xabi init --dry-run

# Inisialisasi XDG layout, nginx.conf, datadir MariaDB, setcap & mkcert CA
xabi init

# Jika xabi init memperingatkan izin setcap, jalankan manual:
sudo setcap 'cap_net_bind_service=+ep' "$(readlink -f "$(command -v nginx)")"

# Verifikasi menyeluruh
xabi doctor

              

            


            

              

                
--dry-run

                
Mencetak seluruh direktori, file konfigurasi, perintah database init, dan capability tanpa memodifikasi sistem.

              

              

                
--force

                
Menulis ulang config.toml, nginx.conf, dan mime.types ke setelan bawaan saat ingin reset konfigurasi.

              

              

                
Default config.toml

                
tld = "test", web_server = "nginx", php_default = "system", port 80/443/3306.

Orkestrasi Layanan User-Space

              
Jalankan, pantau memori & PID real-time, reload konfigurasi secara graceful, dan hentikan layanan dengan bersih.

            

            
          


          

            

              Semua daemon dikelola langsung dari user-space tanpa layanan OS/service wrapper. Setiap layanan mendukung nama spesifik (nginx, php-fpm, mariadb) maupun alias (php, php-cgi, mysql, mysqld).
            


            

              

                powershell • lifecycle daemon
                
              

              
# Jalankan semua layanan (idempoten) atau layanan tertentu saja
xabi up
xabi up nginx php-fpm

# Cek status real-time (alias: xabi st)
xabi status
xabi st

# Graceful reload konfigurasi (atau full restart tanpa --reload)
xabi restart --reload
xabi restart nginx

# Hentikan semua layanan secara terbalik (mariadb -> php-fpm -> nginx)
xabi down

            


            

              

                Arsitektur Proses di Windows: Daemon diluncurkan dengan flag HideWindow + CREATE_NEW_PROCESS_GROUP sehingga tidak pernah memunculkan jendela CMD pop-up. php-cgi.exe berjalan di 127.0.0.1:9000 (PHP_FCGI_CHILDREN=4), PID & RSS dipantau via kernel32.dll / psapi.dll, dan --reload memanggil nginx.exe -s reload.
              

            


            

              

                Arsitektur Proses di Linux: Daemon diluncurkan terisolasi via Setsid: true. php-fpm berkomunikasi lewat unix:$XDG_RUNTIME_DIR/xabi/php.sock, PID & tree RSS dibaca dari /proc/<pid>, reload mengirim SIGHUP (Nginx) dan SIGUSR2 (PHP-FPM), dan stop mengirim SIGTERM (fallback SIGKILL).

Virtual Host & Reverse Proxy

              
Daftarkan domain lokal *.test secara otomatis: auto-detect Laravel/PHP/HTML statis hingga reverse proxy WebSocket untuk Vite, Next.js, atau Go.

            

            
          


          

            
    
              
  • Auto-detect Laravel / Symfony: jika terdapat public/index.php, document root otomatis diarahkan ke folder /public.
    • 
              
  • PHP & Static HTML: mendeteksi index.php, flag --php, atau file .php-version; selain itu dilayani sebagai situs statis dengan try_files $uri $uri/ =404.
    • 
              
  • Reverse Proxy + WebSocket: flag --proxy <port|host:port> mengaktifkan proxy_http_version 1.1, header Upgrade & Connection "upgrade", serta X-Forwarded-*.
    • 
              
  • Atomic Registry & Hosts: menulis , menyimpan metadata di sites.toml, menyuntikkan entri ke blok # BEGIN xabi di hosts, dan me-reload Nginx jika aktif.
    • 
            


            

              

                powershell • kelola virtual host
                
              

              
# 1. Auto-detect dari direktori proyek aktif (Laravel /public, PHP, atau statis)
cd 
xabi add                    # memakai nama folder saat ini -> laravel-app.test

# 2. Reverse proxy ke dev server lokal (Vite/Next/Node/Go) + dukungan WebSocket
xabi add myapp --proxy 3000
xabi add api --proxy 127.0.0.1:8080

# 3. Tentukan folder atau versi PHP secara eksplisit
xabi add legacy --dir  --php 8.2

# 4. Lihat daftar situs, buka di browser, atau hapus situs
xabi ls
xabi open myapp             # atau jalankan 'xabi open' dari dalam folder proyek
xabi rm myapp

Local HTTPS Otomatis (mkcert)

              
Terbitkan sertifikat TLS lokal tepercaya beserta redirect HTTP 301 otomatis untuk satu atau lebih domain proyek.

            

            
          


          

            

              Perintah xabi tls memanggil mkcert untuk membuat pasangan sertifikat <domain>.pem dan <domain>-key.pem (termasuk wildcard *.<domain>) di direktori , memperbarui block Nginx dengan redirect 301 https://$host$request_uri, lalu me-reload Nginx.
            


            

              

                powershell • aktifkan & nonaktifkan HTTPS
                
              

              
# Aktifkan HTTPS untuk situs di direktori kerja saat ini atau nama tertentu
xabi tls
xabi tls myapp

# Buka langsung via HTTPS
xabi open myapp

# Nonaktifkan TLS dan hapus file sertifikat situs
xabi tls myapp --off
# (alias: xabi tls myapp --disable)

            


            

              Prasyarat CA Lokal: Pastikan mkcert -install sudah berjalan (otomatis dijalankan saat xabi init). Jika browser belum mempercayai sertifikat, jalankan ulang mkcert -install dan restart browser.

Multi-Versi PHP & .php-version

              
Ganti PHP global secara instan atau kunci versi PHP berbeda per proyek dengan isolasi upstream FastCGI tanpa saling menimpa.

            

            
          


          

            

              

                powershell • switch global & pin proyek
                
              

              
# Lihat semua instalasi PHP yang terdeteksi (* = aktif global) & .php-version proyek
xabi php

# Ganti PHP default global (update config.toml, shim/symlink, dan reload stack)
xabi php 8.4
# (atau: xabi php use 8.4)

# Pin versi spesifik untuk proyek di direktori kerja saat ini
cd 
xabi php pin 8.3

            


            

              

                

                  
Isolasi Upstream Windows

                  
Global default menggunakan 127.0.0.1:9000. Proyek dengan .php-version atau --php memakai port deterministik 127.0.0.1:90xx (misal 8.1 → 9081, 8.2 → 9082, 8.3 → 9083, 8.4 → 9084).

                

                

                  
Deteksi & .cmd Shims

                  
Mendeteksi PHP di %USERPROFILE%\.local\share\xabi\php\<ver>, C:\php*, C:\tools\php*, C:\laragon\bin\php\php-*, Chocolatey, Scoop, dan PATH; menulis php.cmd & php-cgi.cmd di BinDir.

                

              

            


            

              

                

                  
Isolasi Socket Pool Linux

                  
Global default memakai unix:$XDG_RUNTIME_DIR/xabi/php.sock. Proyek yang di-pin memicu pool khusus ~/.config/xabi/php/php-<ver>.conf dengan socket terpisah php-<ver>.sock (misal php-8.3.sock).

                

                

                  
Deteksi & Symlinks

                  
Mendeteksi PHP di ~/.local/share/xabi/php/<ver>, PATH, /usr/bin, /usr/sbin; memperbarui symlink atomik php & php-fpm di ~/.local/share/xabi/bin/.

                

              

            


            

              Auto-Read Saat Registrasi: Ketika menjalankan xabi add tanpa flag --php, xabi otomatis mencari file .php-version di direktori proyek atau parent terdekatnya.

Utilitas Harian & Shell Completion

              
Akses cepat konfigurasi raw, tailing log lintas platform, tunnel publik, shell database tanpa password, dan autocomplete terminal.

            

            
          


          

            
1. Konfigurasi, Log Streaming, Tunnel & Database

            

              

                powershell • utilitas harian
                
              

              
# Buka config.toml, nginx.conf, php config, sites.toml, atau vhost situs di $EDITOR
xabi conf
xabi conf nginx
xabi conf myapp --path     # cetak path file saja

# Streaming log real-time (-n jumlah baris, --no-follow cetak & keluar, --access log akses)
xabi log nginx -n 50
xabi log nginx --access --no-follow
xabi log mariadb

# Bagikan situs lokal ke internet via cloudflared (default) atau ngrok
xabi share myapp
xabi share myapp --provider ngrok

# Kelola MariaDB lokal ()
xabi db ls
xabi db create myapp_db
xabi db shell myapp_db
xabi db drop myapp_db --force

            


            
2. Setup Shell Completion

            
Script completion mendukung auto-complete seluruh subcommand, nama layanan (nginx, php-fpm, mariadb), serta nama situs dinamis dari xabi ls.


            

              

                

                  powershell • $PROFILE
                  
                

                
# Jalankan di sesi aktif:
xabi completion powershell | Out-String | Invoke-Expression

# Atau simpan permanen ke profil PowerShell ($PROFILE):
Add-Content -Path $PROFILE -Value "`nxabi completion powershell | Out-String | Invoke-Expression"

              

            


            

              

                

                  bash / zsh / fish • shell completion
                  
                

                
# Bash
mkdir -p ~/.local/share/bash-completion/completions
xabi completion bash > ~/.local/share/bash-completion/completions/xabi

# Zsh (pastikan ~/.zsh/completions ada di fpath sebelum compinit)
mkdir -p ~/.zsh/completions
xabi completion zsh > ~/.zsh/completions/_xabi

# Fish
mkdir -p ~/.config/fish/completions
xabi completion fish > ~/.config/fish/completions/xabi.fish

              

            

          

        

      


      

        

          

            
CLI Cheat Sheet — Referensi Cepat

            
Seluruh subcommand, alias, dan flag resmi dari cmd/xabi & internal/commands. Gunakan kotak pencarian Ctrl+K di header untuk memfilter baris.

          

          19 Commands
        


        

          

            
              

                Command
                Sintaks & Flag
                Fungsi
              

            
            
              

                init
                xabi init [--dry-run] [--force]
                Membuat direktori XDG, config.toml, nginx.conf, datadir MariaDB, setcap (Linux), dan mkcert -install.
              

              

                doctor
                xabi doctor
                Memeriksa direktori XDG, binary yang dibutuhkan, port 80/443/3306, izin file hosts, dan cap_net_bind_service.
              

              

                up
                xabi up [service...]
                Menjalankan layanan nginx, php-fpm/php-cgi, dan mariadb secara idempoten.
              

              

                down
                xabi down [service...]
                Menghentikan layanan secara terbalik dan membersihkan file .pid serta .sock.
              

              

                restart
                xabi restart [--reload] [service...]
                Restart penuh, atau graceful reload (SIGHUP/SIGUSR2 di Linux, nginx -s reload di Windows).
              

              

                status st
                xabi status [service...]
                Menampilkan status RUNNING/STOPPED, PID, endpoint, dan RSS memori (+ pemulihan PID yatim).
              

              

                add
                xabi add [name] [--proxy <port|host:port>] [--dir <path>] [--php <ver>]
                Auto-detect Laravel/PHP/statis/reverse proxy WebSocket, menulis vhost Nginx & entri hosts.
              

              

                rm
                xabi rm <name>
                Menghapus file vhost .conf, sertifikat TLS, entri sites.toml, dan baris hosts.
              

              

                ls
                xabi ls
                Menampilkan daftar situs terdaftar (DOMAIN, TARGET, TLS, PHP).
              

              

                open
                xabi open [name]
                Membuka URL situs (http:// atau https://) di browser default (auto-detect CWD jika tanpa argumen).
              

              

                tls
                xabi tls [name] [--off|--disable]
                Menerbitkan sertifikat lokal mkcert + redirect HTTP 301 otomatis, atau mematikan TLS.
              

              

                php
                xabi php [version | use <ver> | pin <ver>]
                Menampilkan PHP terdeteksi, mengganti versi global, atau menulis .php-version per proyek.
              

              

                conf
                xabi conf [config|nginx|php|sites|<site>] [--path]
                Membuka file konfigurasi di $VISUAL/$EDITOR atau mencetak path file dengan --path.
              

              

                log
                xabi log [nginx|php|mariadb|<site>] [-n <lines>] [--no-follow] [--access]
                Streaming log layanan atau situs secara real-time lintas platform.
              

              

                share
                xabi share [name] [--provider <cloudflared|ngrok>]
                Membuka public tunnel ke situs lokal dengan host header & TLS pass-through otomatis.
              

              

                db
                xabi db [shell [name] | ls | create <name> | drop <name> [--force]]
                Mengelola database MariaDB/MySQL user-space atau membuka SQL shell tanpa mengetik password.
              

              

                completion
                xabi completion <bash|zsh|fish|powershell>
                Mencetak script shell completion termasuk daftar situs dinamis dari xabi ls.
              

              

                help
                xabi help [command] (-h, --help)
                Menampilkan ringkasan seluruh perintah atau detail usage subcommand tertentu.
              

              

                version
                xabi version (-V, --version)
                Mencetak versi binary xabi yang terpasang.
